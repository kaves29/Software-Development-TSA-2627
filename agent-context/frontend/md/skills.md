# Frontend skills

Use this index to choose a skill for Speakly frontend work. Follow the setup guide to check sources and share approved files with the team. [Agent setup guide](../../project/md/user_agent_setup.md)

| Skill | What it does | Availability in this repo |
| --- | --- | --- |
| Frontend Design (`frontend-design`) | Guides interface layout, typography, color, accessibility, and design review. | Installed. [Frontend Design](../skills/frontend-design/SKILL.md) |
| UI/UX Pro Design | Supports interface and user experience design. The exact capabilities depend on the installed package. | Installed. [UI/UX Pro Max](../skills/ui-ux-pro-max/SKILL.md) |
| Impeccable | Helps refine interface design. The exact commands depend on the installed package. | Upstream identified. Manual skill package under review. |
| Animation and motion skills | Guide transitions and interaction feedback, including reduced-motion behavior. | Installed. [Unslop Motion](../skills/unslop-motion/SKILL.md) |

Keep approved reusable skill packages in [frontend/skills](../skills/), including their `SKILL.md`, any required supporting files, and applicable license and attribution. This index records the skills discussed for the project. Codex discovers linked packages through the project’s `.agents/skills/` directory in a new session.
