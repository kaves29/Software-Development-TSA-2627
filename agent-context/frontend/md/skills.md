# Frontend skills

Use this index to choose a skill for Speakly frontend work. Follow the setup guide to check sources and share approved files with the team. [Agent setup guide](../../project/md/user_agent_setup.md)

| Skill | What it does | Availability in this repo |
| --- | --- | --- |
| [Playwright Browser Automation](../skills/playwright-skill/SKILL.md) | Automates browser interactions and checks responsive layouts, screenshots, links, and user flows. Requires Node.js 20+, npm, Playwright, and a browser. | Available in the frontend skills folder. |
| Frontend Design (`frontend-design`) | Guides interface layout, typography, color, accessibility, and design review. | Upstream source identified in the setup guide. |
| UI/UX Pro Design | Supports interface and user experience design. The exact capabilities depend on the installed package. | Local package name and files need verification. |
| Impeccable | Helps refine interface design. The exact commands depend on the installed package. | Local files need verification. |
| Animation and motion skills | Guide transitions and interaction feedback, including reduced-motion behavior. | Exact installed skill names and files need verification. |

Keep approved reusable skill packages in [frontend/skills](../skills/), including their `SKILL.md`, any required supporting files, and applicable license and attribution. This index records the skills discussed for the project. The team needs the original files or approved upstream sources to install them.
